# Bilingual Education — 研習互動遊戲

3 小時雙語教育研習「從興南到辰光」的四個段落互動遊戲。
學員用手機掃 QR Code 就能加入，作答即時回到主持人畫面。

**線上網址：** https://cyysongyy.github.io/bilingual-education/

---

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 遊戲首頁。學員輸入暱稱後選關；內建 QR Code 與「投影用大 QR」 |
| `g1.html` | 關卡 1 · 三種語言看圖分類（PART I 觀念地基） |
| `g2.html` | 關卡 2 · CLIL 教案拼裝廠（PART II 興南） |
| `g3.html` | 關卡 3 · SEL 辰光句型挑戰（PART III 辰光） |
| `g4.html` | 關卡 4 · 校長的兩難（PART IV 行政推動） |
| `host.html` | 主持人即時看板（投影用，每 10 秒自動更新） |
| `common.js` | **唯一要修改的檔案** — 貼上 Apps Script 網址 |
| `style.css` | 共用樣式（與簡報同一套配色） |
| `art.js` | 遊戲用的向量插圖（純 SVG，不需要圖檔） |
| `Code.gs` | Google Apps Script 後端（貼進試算表用） |

## 一、接上 Google Sheet（3 分鐘，只要做一次）

不接也能玩，但主持人畫面會看不到學員作答。

1. 開一份新的 Google 試算表，命名為「雙語研習遊戲紀錄」
2. **擴充功能 → Apps Script**
3. 把 `Code.gs` 的內容整個貼進去（取代原本的 `myFunction`），儲存
4. 右上角 **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」→ 第一次會要求授權，一路允許
5. 複製產生的網址（結尾是 `/exec`）
6. 打開 `common.js`，把網址貼到第 12 行：
   ```js
   const GAS_URL = 'https://script.google.com/macros/s/AKfycb....../exec';
   ```
7. 把 `common.js` 重新上傳到 GitHub → 完成

> 之後改題目、改文案都只要重傳 HTML，**不需要**重新部署 Apps Script。

## 二、研習現場流程

**開場（投影）**

1. 電腦開 `index.html` → 點「投影用大 QR Code」→ 全螢幕投出
2. 學員掃碼 → 輸入暱稱與服務學校 → 進入關卡選單
3. 選單最上面是 **開場：英雄旅程**（https://cyysongyy.github.io/heros-journey/ ），
   讓大家先玩 3 分鐘再開始講——推動任何改變，本來就是一場英雄旅程

**四個段落，講到哪一段就玩哪一關**

| 時間 | 簡報頁 | 關卡 | 約需 |
|---|---|---|---|
| 00:36 | **P15** | ① 三種語言看圖分類 | 5 分 |
| 01:44 | **P40** | ② CLIL 教案拼裝廠 | 8 分 |
| 02:20 | **P51** | ③ SEL 辰光句型挑戰 | 7 分 |
| 02:45 | **P61** | ④ 校長的兩難 | 8 分 |

> 簡報 P15 / P40 / P51 / P61 各有一張專屬 QR 頁，講完那一段直接投影，學員掃碼就進得去。

**主持人畫面**

另開一個分頁（或另一台電腦）打開 `host.html`，投影出來：

- **總覽** — 加入人數、各關完成數、平均得分率
- **① 三種語言** — 排行榜
- **② 教案牆** — 全場的三欄簡案，可直接點名討論
- **③ 情緒雲 ＋ 文字牆** — 全場 Check-in 情緒分布、每個人的 `I am ___. I can ___.`
- **④ 校長的兩難** — 校長型分布＋每一題的選擇分布（**最適合帶討論：看哪一題大家分得最開**）
- **參加者** — 名單與完成進度

## 三、分場次（同一份網頁辦多場）

網址後面加 `?s=場次代碼`，資料就會分開統計：

```
https://cyysongyy.github.io/bilingual-education/?s=0812chiayi
```

主持人畫面會自動沿用同一個場次代碼。
研習結束想清資料，可在 Apps Script 編輯器裡改 `clearSession()` 的場次代碼後執行。

## 四、常見狀況

| 狀況 | 處理 |
|---|---|
| 右上角顯示「離線模式」 | `common.js` 的 `GAS_URL` 還沒貼，或貼錯（要以 `/exec` 結尾） |
| 主持人畫面顯示「連線失敗」 | Apps Script 部署時「誰可以存取」沒有選「所有人」 |
| 學員換手機後進度不見 | 進度存在瀏覽器 localStorage，換裝置會重來；已送出的成績仍在 Sheet 裡 |
| 現場網路不穩 | 遊戲本身純前端，離線也能玩完；只是成績上不去 |
| 想改題目 | 直接編輯對應的 `gN.html`，題庫都在檔案上方的陣列裡 |
